# Student Management Database System

## Project Overview
This is a MySQL-based Student Management Database project developed to practice SQL and basic Database Administration concepts.

## Technologies Used
- MySQL
- SQL
- OneCompiler

## Database Tables
- Students
- Courses
- MarksHistory
- Students_Backup
- Courses_Backup
- MarksHistory_Backup

## Features
- Student and course record management
- Primary and Foreign Keys
- SQL Joins
- Views
- Stored Procedures
- Triggers
- Transactions (COMMIT and ROLLBACK)
- Backup and Recovery practice
- Indexing and Query Optimization
- Database Reporting

## How to Run
1. Open the SQL file.
2. Copy the SQL code.
3. Open a MySQL environment.
4. Execute the SQL script.

## Learning Outcomes
- Understanding relational databases
- Writing SQL queries
- Managing database records
- Understanding database security
- Practicing basic database administration
